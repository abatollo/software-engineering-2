# Обучающая онлайн-система ООО «Нондус»

Учебный проект по дисциплине «Программная инженерия».

Система предназначена для онлайн-обучения веб-разработке в ООО «Нондус». В ней обучающиеся проходят курсы, выполняют практические задания в браузерной песочнице и следят за своим прогрессом, а наставники и кураторы проверяют работы и сопровождают обучение. Учебные материалы, задания и результаты хранятся в одном месте, а не в разных папках и таблицах.

## Пользователи

Гость, обучающийся, наставник, куратор, методист (преподаватель), специалист сопровождения, специалист по работе с выпускниками, руководитель программы.

## Основные возможности

- просмотр открытых уроков без регистрации;
- регистрация, личный кабинет, запись на курс и оплата обучения;
- уроки, видеоматериалы и тесты;
- практические задания в браузерной песочнице с автосохранением черновика;
- проверка работ наставником с оценкой и комментарием;
- контроль прогресса и отстающих обучающихся куратором;
- сертификат после окончания курса и статистика для руководителя программы.
