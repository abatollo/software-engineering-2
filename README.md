# Обучающая онлайн-система ООО «Нондус»

Учебный проект по дисциплине «Программная инженерия».
Выполнил: Батолло Александр Николаевич, группа ЗБ-ВР-23.

Система предназначена для онлайн-обучения веб-разработке в ООО «Нондус». В ней обучающиеся проходят курсы, выполняют практические задания в браузерной песочнице и следят за своим прогрессом, а наставники и кураторы проверяют работы и сопровождают обучение. Учебные материалы, задания и результаты хранятся в одном месте, а не в разных папках и таблицах.

Все документы проекта лежат в папке `docs`.
